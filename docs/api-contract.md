# API contract plan

**Status:** Foundation, account/onboarding, private Passport, intents/Discover/connections, persistent direct chat, Cohort directory/membership/posts, Pod creation/membership/chat, referral quota/history, and member report routes are implemented locally. Push/WebSocket and several advanced management routes remain planned. OpenAPI is generated by FastAPI.

## Conventions

- Base path: `/api/v1`.
- JSON request/response bodies validated with Pydantic v2.
- UUID IDs; UTC RFC 3339 timestamps.
- Bearer authentication for member APIs; no client-supplied user ID is trusted for identity or authorization.
- Stable error envelope: `{"error":{"code":"...","message":"...","request_id":"...","details":{}}}`. Do not return stack traces or private data.
- Paginated collection routes use opaque cursors and bounded page sizes.
- Mutating requests that may be retried accept an idempotency key.
- WebSockets are authorized against the same current membership/connection rules as REST; reconnect does not bypass revocation.

| POST | `/api/v1/auth/logout` | unauthenticated | Revoke session using its refresh token |
| POST | `/api/v1/auth/logout-all` | authenticated | Revoke all member sessions |

| GET | `/api/v1/me/consent-policies` | authenticated | Return current Terms/Privacy policy versions and URLs; unavailable until approved documents are configured |
| POST | `/api/v1/me/consents` | authenticated | Record versioned Terms/Privacy acceptance and separate import consent |
| GET | `/api/v1/me/profile` | authenticated | Read the current member's private draft profile and provenance |
| PUT | `/api/v1/me/profile` | authenticated | Validate and save reviewed/manual fields and privacy audience preference; profile remains unpublished/private |

| GET | `/api/v1/me/bridge-score` | authenticated | Read own score state, final score when ready, calculated time, safe guidance, and separate verification state |
| GET | `/api/v1/me/bridge-score/history` | authenticated | Read up to 50 of own score snapshots; internal rubric dimensions are never returned |
| GET | `/api/v1/me/passport` | authenticated | Read the current member's private Passport preview; no public share URL is created |
| POST | `/api/v1/me/resume-uploads` | planned | Request a short-lived private object upload after resume-processing consent; unavailable until private storage and scanning are configured |
| POST | `/api/v1/me/resume-uploads/{id}/complete` | planned | Verify uploaded object metadata and enqueue parsing |
| GET | `/api/v1/me/imports/{id}` | authenticated | Poll import state and retryable failure code |
| GET/DELETE | `/api/v1/me/identities/{provider}` | authenticated | Inspect or disconnect a linked provider and revoke/delete stored token material where supported |

Google identity tokens are verified against Google's signing keys and the configured server OAuth audience. Only the provider subject and needed verified claims map to a Bridge account; Google tokens are never returned by these APIs. Bridge access tokens expire after 15 minutes; refresh tokens rotate and are stored as hashes.

## Contract security requirements

- Authenticate and authorize on every route, including nested resource IDs.
- Validate uploaded file type/size/content and store objects privately.
- Redact sensitive fields from errors/logs. Rate-limit auth, messaging, upload, and referral endpoints.
- Enforce the intent maximum, Pod membership/capacity, connection-required chat, referral eligibility, and lifetime referral limit in backend transactions.
